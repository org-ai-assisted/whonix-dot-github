# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately, not through a public issue,
pull request, or forum post.

Contact: adrelanos@whonix.org

Sensitive reports can be encrypted with the maintainer's OpenPGP key:

- Fingerprint: 916B 8D99 C38E AF5E 8ADC 7A2A 8D66 066A 2EEA CCDA
- Key: https://github.com/adrelanos.gpg
- Details and verification: https://www.whonix.org/wiki/Signing_Key

We will acknowledge your report, keep you informed of progress, and coordinate
public disclosure once a fix is ready.
